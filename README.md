# Ly-Prum | 名刺発注管理システム デモ

**Ly-Prum** が提供する名刺発注管理サービスのインタラクティブUIデモです。  
ログイン不要・ブラウザのみで6つのロール別画面をお試しいただけます。

🔗 **デモURL（PC版）**: https://ly-prum.github.io/ly-prum-mock/  

🔗 **デモURL（スマホ版）**: https://ly-prum.github.io/ly-prum-mock-mobile/

---

## ロール一覧

| ロール | 対象 | 主な機能 |
|---|---|---|
| 管理者・上層部 | エンド企業 経営層 | 全社ダッシュボード・ROI試算 |
| 総務担当 | エンド企業 総務 | 発注承認・校了・受発注業務 |
| 現場スタッフ | エンド企業 社員 | 名刺発注・プレビュー確認 |
| 制作チーム | Ly-Prum 制作 | データアップロード・進捗管理 |
| 営業 (Growth Link) | GL 営業担当 | 提案アラート・受注管理・ROI試算 |
| 管理者 (Growth Link) | GL 管理職 | 受注KPI・取引先管理 |

---

## 技術スタック

- **Font Awesome 6** — アイコン

- **GitHub Pages** — ホスティング
